# How to work in this repo

- Respond in English.
- Give direct, honest feedback. Don't soften criticism or hedge.
- Never invent facts. If something is unknown, write "UNKNOWN" or "TBD" instead of guessing.
- Don't add boilerplate disclaimers.
- Each problem gets its own folder (e.g. `droneacharya/`) with its own notes. Read that folder's README before working in it.
- Put written deliverables in `docs/` as Markdown unless I ask for another format.
- Before changing existing files, say what you plan to change.
